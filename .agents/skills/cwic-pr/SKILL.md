# CWIC Pull Request

Inspect the current diff, affected country tags, and relevant validation evidence. Write or update the pull-request description using `.github/PULL_REQUEST_TEMPLATE.md`: describe the player-facing change and why it is needed, mark affected mod areas, list tags, and complete only truthful checklist items.

Include in-game test steps and outcomes for gameplay changes. For interface, portrait, or graphics changes, request or attach concise visual evidence when available. Link an existing issue when relevant.

Keep the PR focused and call out any untested runtime path. Do not create, push, publish, comment on, or modify a pull request unless the user explicitly authorizes that external action.
